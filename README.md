# Haila Partner API — Test Client

Reference client for the Haila Partner API (`/api/partner/v1`), built with **Vue 3 + Vite + PrimeVue 4** (dark Dracula theme). Use it to explore the API and as a starting point for your own custom client.

| Language | Document |

| English | [Guide in English](docs/en.md) |
| Español | [Guía en español](docs/es.md) |

## Quick start

From this folder:

```bash
npm install
npm run dev
```

Open `http://localhost:5199`, go to the **Conexão / Connection** tab and fill in the engine URL and your partner `X-Api-Key`.

Other scripts: `npm run build`, `npm run preview`, `npm run typecheck`.
